# Word Detective

## Description
A Python text-analysis program that examines a sentence and extracts several word and character statistics.

## Features
- Counts the number of words
- Finds the longest word
- Finds the shortest word
- Counts unique words
- Finds the most frequently occurring word
- Counts vowels
- Counts consonants
- Counts spaces

## Technologies Used
- Python

## Concepts Used
- String methods
- Lists
- Dictionaries
- Loops
- Conditional statements
- `len()`, `sum()`, and character methods
- Frequency counting

## How to Run
```bash
python word.py
```

## Note
The current program analyzes a sentence defined directly in the source code rather than asking the user to enter a sentence.
