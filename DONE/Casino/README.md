# Mini Casino

## Description
A command-line Python casino game where the player starts with 100 coins and can play a number-guessing game or a coin-flip game.

## Features
- Starts with 100 coins
- Guess a number from 1 to 10
- Earn 30 coins for a correct guess
- Lose 10 coins for an incorrect guess
- Play a Heads/Tails coin flip
- Earn 20 coins for a correct coin flip
- Lose 10 coins for an incorrect coin flip
- Game stops when the player runs out of coins

## Technologies Used
- Python
- `random` module

## Concepts Used
- Functions
- Loops
- Conditional statements
- User input
- Random number and choice generation
- Variables and arithmetic operations

## How to Run
```bash
python casino.py
```
