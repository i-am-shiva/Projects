# Number Guessing Game

## Description
A Python number guessing game in which the computer randomly selects a number between 1 and 100 and the player keeps guessing until the correct number is found.

## Features
- Random number generation
- Gives a hint after every incorrect guess
- Counts the total number of guesses
- Continues until the correct number is entered

## Technologies Used
- Python
- `random` module

## Concepts Used
- `while` loop
- Conditional statements
- User input
- Random number generation
- Counters

## How to Run
```bash
python "guess no.py"
```
