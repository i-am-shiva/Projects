# Diamond Thief

## Description
A simple Python detective program that identifies possible suspects by matching two clues: the thief's shirt color and the time the thief was seen.

## Features
- Stores suspect information using a dictionary
- Checks the shirt-color clue
- Converts times into comparable `datetime.time` values
- Filters suspects seen between 9:30 PM and 10:00 PM
- Prints the suspects who match both clues

## Technologies Used
- Python
- `datetime` module

## Concepts Used
- Dictionaries
- Loops
- Conditional statements
- Lists
- Date and time parsing
- Dictionary iteration

## How to Run
```bash
python thief.py
```
