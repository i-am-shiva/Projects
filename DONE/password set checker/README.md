# Password Set Checker

## Description
A Python password validation program that checks whether a password satisfies a set of basic security requirements.

## Validation Rules
- At least 8 characters
- At least one uppercase letter
- At least one lowercase letter
- At least one digit

If any requirement is missing, the program reports the missing requirement.

## Technologies Used
- Python

## Concepts Used
- Strings
- `len()`
- `any()`
- Character methods such as `isupper()`, `islower()`, and `isdigit()`
- Lists
- Loops
- Conditional statements

## How to Run
```bash
python passcheck.py
```
