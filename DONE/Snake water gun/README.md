# Snake Water Gun

## Description
A command-line implementation of the Snake Water Gun game. The player selects Snake, Water, or Gun, and the computer makes a random choice.

## Game Rules
- Snake beats Water
- Water beats Gun
- Gun beats Snake
- Matching choices result in a tie

## Features
- Random computer choice
- User input
- Win, lose, and tie detection
- Uses dictionaries to map choices to values

## Technologies Used
- Python
- `random` module

## Concepts Used
- Dictionaries
- Random choice
- Conditional statements
- User input
- Variables

## How to Run
```bash
python "SWG game.py"
```
