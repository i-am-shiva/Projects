# Expense Tracker

## Description
A command-line Python expense tracker for recording and analyzing Food and Transport expenses.

## Features
- Add an expense
- Show stored expenses
- Calculate total spending
- Find the highest expense by category
- Calculate spending by category
- Exit through a menu

## Technologies Used
- Python

## Concepts Used
- Lists
- Dictionaries
- Functions
- Loops
- Conditional statements
- `sum()` and `max()`
- User input

## How to Run
```bash
python expense.py
```
