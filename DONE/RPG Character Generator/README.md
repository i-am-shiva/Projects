# RPG Character Generator

## Description
A Python program that creates an RPG character based on the player's name, age, and selected character class.

## Character Classes
- Warrior
- Mage
- Rogue

Each class has its own Health, Attack, and Defense statistics.

## Features
- Takes character details from the user
- Assigns class-specific statistics
- Stores character information in a dictionary
- Displays the generated character

## Technologies Used
- Python

## Concepts Used
- Functions
- Dictionaries
- Conditional statements
- User input
- Dictionary unpacking
- Loops

## How to Run
```bash
python generator.py
```
