# Python Projects

A collection of Python projects I built while learning and strengthening my Python programming fundamentals.

These projects started as small programming exercises and gradually helped me practice problem-solving, functions, loops, data structures, file handling, string manipulation, and Python modules.

## 📂 Projects

All completed projects are organized inside the `DONE` folder.

| Project | Description | Concepts |
|---|---|---|
| 🎰 [Casino](./DONE/Casino) | Command-line casino game with number guessing and coin flipping | Functions, loops, random module, conditions |
| 💎 [Diamond Thief](./DONE/Diamond%20Thief) | Detective program that identifies suspects using clues | Dictionaries, loops, datetime, conditions |
| 💰 [Expense Tracker](./DONE/Expense%20Tracker) | CLI application for tracking and analyzing expenses | Functions, lists, dictionaries, loops |
| 🎯 [Guess No](./DONE/Guess%20no) | Number guessing game using random number generation | Loops, conditions, random module |
| 🔐 [Password Set Checker](./DONE/password%20set%20checker) | Checks whether a password satisfies basic requirements | Strings, loops, conditions, `any()` |
| 🧙 [RPG Character Generator](./DONE/RPG%20Character%20Generator) | Generates RPG characters with class-specific statistics | Functions, dictionaries, conditions |
| 🐍 [Snake Water Gun](./DONE/Snake%20water%20gun) | Command-line Snake Water Gun game against the computer | Dictionaries, random module, conditions |
| 🧩 [Word Detective](./DONE/Word%20Detective) | Analyzes a sentence and extracts word and character statistics | Strings, lists, dictionaries, loops |
